# BybitSpotTriangularArbitrage

v1.0 | Faster than REST API | Socket API | Live Updates
This is the new version of Bybit Spot Triangular Arbitrage Finder.

## Key Features
- Built on Websockets instead of REST API
- 20x faster
- No need to install CORS Chrome extensions
- Runs Live
- Simplified Interface

## How to Run
Follow the instructions below:

1. Install Node.js [link](https://nodejs.org/)
2. Download and unzip this package.
3. Go to the current folder in the command prompt and run the commands below:
npm install
node index.js
4. Wait until the program loads.
5. Then go to [http://127.0.0.1:3000/](http://127.0.0.1:3000/) to access the tool.
